Copia de seguridad
Todos los datos viven únicamente en este dispositivo y este navegador. Si se borra el historial del navegador o cambiás de equipo, se pierden — por eso conviene exportar seguido.
Todavía no exportaste ninguna copia.
Al importar, podés elegir si reemplaza todos los datos actuales o si los suma a lo que ya tenés cargado.
Reiniciar todos los datos
Borra equipos, accesorios, movimientos, pedidos, planes reserva y proveedores de este dispositivo. No se puede deshacer.
Nube de Digital Store (Vercel)
Guarda tus datos en la nube y los muestra igual en todos tus dispositivos. Se actualiza solo cada pocos segundos. Funciona en el sitio publicado en Vercel.
Una vez, en Vercel → Settings → Environment Variables: SYNC_PASSWORD (la contraseña que elijas), SUPABASE_URL y SUPABASE_SERVICE_KEY. Después, Redeploy. Los datos se guardan en Supabase y solo se leen o escriben con la contraseña.
Conectar a Firebase
Pegá la URL de tu Realtime Database y todos los dispositivos que la usen van a ver los mismos datos.
Cómo crear la base (una vez): 1) console.firebase.google.com → crear proyecto. 2) Realtime Database → Crear base de datos → modo de prueba. 3) Copiá la URL (termina en firebaseio.com) y pegala arriba. 4) En cada otro dispositivo, pegá la misma URL.
Conectar a Supabase (clave pública)
Guarda directo en tu tabla de Supabase con la clave pública. Para proteger con contraseña usá la Nube (Vercel).
Una vez: supabase.com → New project → SQL Editor → ejecutá el SQL del README (crea la tabla y la política de acceso) → Project Settings → API: copiá la URL y la clave anon/publishable.
Base de datos de la plataforma (solo en el link publicado)
Alternativa sin configuración: solo funciona abriendo el link publicado de claude.ai, con la misma cuenta en todos los dispositivos.
Abrí este mismo link publicado en cada celular o computadora del equipo, conectado a la misma cuenta. Los cambios se comparten solos y en vivo — no hace falta ningún paso extra. Si abrís el archivo .html suelto en vez del link publicado, esta sincronización no está disponible (usá "Backup y datos" en ese caso).
Sincronizar por archivo (solo Chrome/Edge de PC)
Alternativa sin nube: vinculá la app a un archivo de datos. Si ese archivo vive dentro de una carpeta de Google Drive, OneDrive o Dropbox, se actualiza solo entre computadoras. No funciona en celular.
Tu navegador no permite este tipo de sincronización (funciona en Chrome o Edge, en computadora). Usá la sincronización por la nube de arriba si necesitás celulares.
Paso a paso: 1) Creá una carpeta sincronizada de Google Drive/OneDrive. 2) Tocá "Crear archivo nuevo" y guardalo ahí. 3) En cada otra computadora, tocá "Vincular archivo existente" y elegí ese mismo archivo.
Umbrales de margen
Definen cuándo un margen se muestra como bajo, saludable o excelente en toda la app.
Por debajo del primer número se marca en rojo, entre los dos en amarillo, y por encima del segundo en verde.
