# Digital Store · Stock Manager

App estática (un solo `index.html`). No necesita build ni dependencias.

## Subir a Vercel
1. Subí esta carpeta a un repositorio de GitHub (botón "Add file → Upload files").
2. En vercel.com → Add New → Project → importá el repositorio.
3. Framework Preset: **Other**. Dejá vacíos Build Command y Output Directory. Deploy.

## Con la terminal (alternativa)
    npm i -g vercel
    cd digital-store
    vercel --prod

## Después de publicar
- Entrá a la URL, creá la cuenta de administrador y guardá el código de recuperación.
- Más → Copia y sincronización: pegá la URL de Firebase y tocá "Guardar y conectar".
